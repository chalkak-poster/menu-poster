# 찰칵포스터 · 행운랩스 서비스

카페·음식점 사장님이 메뉴 사진 한 장으로 매장용 포스터를 만드는 웹 서비스입니다.

- **운영 주소:** https://chalkak-poster.github.io/menu-poster
- **GitHub 저장소:** https://github.com/chalkak-poster/menu-poster (`site/` 폴더 내용이 그대로 올라가 있음)

## 바로 열어 보기
- PC: 이 폴더의 `index.html`을 크롬이나 엣지로 열면 됩니다.
- 폰: 위 운영 주소로 들어가세요. (AI 누끼는 운영 주소에서 가장 잘 됩니다)

## 화면 구성
1. **서비스 소개(웰컴) 화면** — 들어올 때 항상 먼저 나와요. 특장점 3가지, 만드는 4단계, 완성 포스터 예시, 스크롤 애니메이션
2. **제작 화면** — 소개에서 "포스터 만들기"를 누르면 이동 (`#make`)
   1. 메뉴 사진 올리기 (끌어다 놓기 · 선택 · 붙여넣기)
   2. 음식만 오려내기
      - ✨ AI 누끼: 버튼 한 번에 자동 2단계 (전체에서 찾기 → 음식마다 확대해서 한 번 더)
      - 음식 영역 지정해서 다시 찾기 / 접시까지 포함 / 세부 조정(가장자리·부드럽게·정밀도)
      - 접시 원형으로 오리기 / 원본 사진 그대로
      - ✏️ 직접 수정하기: 지우개·복원·되돌리기, 두 손가락 확대·이동, 휠 확대(최대 6배)
   3. 사진 보정 (음식 부분만 보고 자동 보정 + 슬라이더)
   4. 배경 바꾸기 (30종, 분류별 · 브랜드 색 · 칠판 · 내 배경)
   5. 틀과 문구 (템플릿 4종 · A4/정사각/스토리 · 빈 칸은 안내 문구로 표시, 저장 전 확인)
3. **모바일 미니 미리보기** — 큰 미리보기가 화면 밖으로 나가면 반투명 미니 포스터가 떠요 (탭하면 크게)
4. **하단 정보** — 행운랩스 서비스 표기, 사업자 정보(빈칸), 이용약관·개인정보처리방침·오픈소스 라이선스

## 폴더 구조
| 경로 | 내용 |
|---|---|
| `src/app.html` | **원본 코드** (여기를 고칩니다) |
| `backgrounds/` | 배경 30장 + `manifest.json` (이름·분류·밝기) |
| `index.html` | PC에서 바로 여는 완성본 (빌드 결과) |
| `site/` | 웹사이트에 올리는 파일 전체 (빌드 결과 + 약관 페이지 + 아이콘) |
| `dist/artifact.html` | claude.ai 비공개 링크용 (AI 누끼 안 됨) |
| `tools/build.py` | `src/app.html` + 배경 → `index.html`, `site/index.html`, `dist/artifact.html` |
| `tools/make_pages.py` | 이용약관·개인정보처리방침·오픈소스 라이선스 페이지 생성 |
| `tools/make_brand_assets.py` | 파비콘·홈 화면 아이콘·공유 미리보기 이미지 생성 |
| `tools/make_backgrounds.py` | 지금의 배경 30장을 만든 코드 |

## 고치고 올리는 순서
1. `src/app.html` 수정
2. `python tools/build.py`
3. `site/` 안의 파일을 GitHub 저장소 **맨 위 폴더**에 덮어쓰기 (저장소의 `project/` 폴더는 이 원본 백업입니다)

## 사업자 정보 채우기
사업자 등록 후 아래 두 곳의 빈칸(`[대표자]`, `[사업자등록번호]` 등)을 채우고 다시 빌드하면 됩니다.
- `src/app.html`의 `const BIZ = {...}` → 하단 정보
- `tools/make_pages.py`의 `BIZ = dict(...)` → 약관 세 페이지 (`python tools/make_pages.py`)

## 비용 구조 (서버 비용 0원)
모든 처리가 사용자 기기 브라우저 안에서 이루어집니다. 사진은 서버로 전송되지 않습니다.
AI 누끼 모델은 처음 한 번 IMG.LY 무료 서버에서 받아오고, 이후에는 기기에 저장돼 바로 처리됩니다.

## 보안
- 웹사이트 버전에는 보안 정책(CSP)이 들어 있어, 허용한 출처(jsDelivr·IMG.LY·Google Fonts)에서만 코드와 파일을 불러옵니다.
- 코드에 API 키·비밀번호 같은 비밀값은 없습니다. 앞으로 유료 기능을 넣을 때도 키는 절대 이 코드에 넣지 말고 서버에 두세요.

## 라이선스 주의
AI 누끼 라이브러리(@imgly/background-removal)는 **AGPL-3.0**입니다. 저장소를 공개해 두어 소스 공개 조건은 충족하고 있습니다.
유료 서비스로 운영할 때는 공개를 유지하거나, IMG.LY 상용 라이선스를 사거나, 상업 이용이 가능한 다른 모델로 바꾸는 것 중 하나를 정해야 합니다. 정식 출시 전 법률 검토를 받으세요.
